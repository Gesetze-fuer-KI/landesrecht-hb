# Landesrecht Bremen – nicht verfügbar

**Das Landesrecht von Bremen fehlt in [Gesetze für KI](https://gesetze-fuer-ki.de) – nicht, weil wir es nicht wollen, sondern weil das Landesportal es nicht zulässt.**

Das offizielle Transparenzportal transparenz.bremen.de beantwortet jede Anfrage aus einem Rechenzentrum mit **403 Forbidden**, schon die Startseite. Das gilt für die Server von GitHub ebenso wie für unseren eigenen Server bei Hetzner. Von einem privaten Internetanschluss aus lädt dieselbe Seite ganz normal. *(geprüft am 20.10.2026)*

Wer die Gesetze von Hand im Browser liest, kommt also durch, ein freies, gemeinnütziges Projekt, das sie jede Nacht abgleicht, nicht. Einen Download des gesamten Bestands oder eine offene Schnittstelle gibt es nicht. Die Sperre zu umgehen, etwa über einen privaten Anschluss, kommt für uns nicht in Frage.

**Das ist nicht hinnehmbar.** Gesetze sind amtliche Werke und nach § 5 UrhG gemeinfrei. Sie binden jede Bürgerin und jeden Bürger in Bremen, und Unwissenheit schützt bekanntlich nicht vor Strafe. Trotzdem darf man sie nur Seite für Seite im Browser lesen, nicht weiterverwenden, nicht durchsuchbar machen, nicht einem KI-Assistenten zeigen. Der Bund macht es seit Jahren vor: gesetze-im-internet.de stellt das gesamte Bundesrecht als offene Daten bereit.

**Was helfen würde:** Bremen veröffentlicht sein Landesrecht als offene Daten oder lässt einen schonenden automatischen Abruf zu. Unser Abgleich ist fertig und kann sofort starten. Wenn Sie das auch wollen, schreiben Sie der zuständigen Stelle – die Vorlage unten können Sie übernehmen – und gern auch uns: [kontakt@gesetze-fuer-ki.de](mailto:kontakt@gesetze-fuer-ki.de).
